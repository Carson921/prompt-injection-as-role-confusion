# GPT-OSS-120B 六角色优化：三张 A40、六小时 warm start

协议日期：2026-10-27。用户已授权按本计划执行，通过 SSH 别名 `runpod` 使用同机三张 A40。六小时从本轮首次 CUDA 模型加载前开始，设置独立截止监督器；旧实验的截止时间和预检不复用。CPU 代码、数据及环境恢复在 GPU 计时前完成。

## 目标和固定边界

保留纯文章训练约束，改善原生 system/developer 的迁移识别，同时保持对角色混淆的诊断能力。120B MXFP4 本体冻结，固定原 16 个有序 pre-o_proj 头、1024 维 FP16 特征和六类顺序。原始角色标签、schema 和控制标记不作为监督目标。

父模型为上一轮 `mlp128-seed17` 最佳 epoch30，SHA256 `22cb7251cd96c81d8d1225311b1e3048499850f738b56f4b57040ad7bedf4125`。继承权重及 FIT mean/scale；重新初始化 AdamW、epoch、早停计数和随机状态。旧 last.pt 的 optimizer 属于末轮38，不与最佳 epoch30 权重拼接。新实验内的中断恢复使用其自身 last.pt。

原 57 个 AgentDojo 任务属于已观察的回归集，不用于拟合、标准化、选头、选候选或早停。固定原特征接口后，直接离线读取已有 calls/input.npz 与 generation_probe.npz 的原始 head_features，无需再次提取，也不进行 teacher-forced 替代。358 个未捕获停止标记保持排除。

## 数据及审计

预声明标准档 512 FIT /128 DEV /128 全新 TEST 源文章，保守档 256 FIT /128 DEV /128 TEST。C4/Dolma3 各半。仅根据计时和显存选择可完成的最大档位，随后冻结清单；两个档位均无法完成时交付实际完成范围，不缩减 TEST 或延长截止。

FIT/DEV 优先复用各自旧文章池，按长度资格补齐同版本公开非对话文章。旧 C4 validation 池长文不足时，使用同 revision 的 en/train 补充并在 provenance 明记 split 变化；Dolma3 维持原六主题来源。所有补充文章按固定哈希分区，并排除旧来源、可定位历史文章、规范化 URL/正文及 SimHash 半径三近重复。新 TEST 不从旧已观察 TEST 取文章。

每源构造同一正文分别置于六种原生角色的 paired 版本，再构造一条合法单轮或 K=2/3 多轮 context。正文长度 128/256/512/1024 token 分层，每角色最多96个目标、正文四分位各24个；共同可对齐位置记录字符边界、token ID 和同跨度 occurrence。长度资格不足不伪称达到配额。

context 保持合法 SD 顺序，覆盖原五种单轮结构，变化 S/D 长度及 D 文章在工具定义前后、description 中的位置。完整输入上限4096，结构/schema 不评分，不截断已渲染消息。实际输入逐条 retokenize，独立检查角色/文章 spans/混合 BPE/QT配对及 source 划分；固定50篇 FIT/DEV 样本作 LLM 代理文章审阅，明确非人类 gold。完整正文、特征和历史去重摘要保存在仓库外。

CPU准备审阅发现的活动索引、图片目录和拼接卡片页先保留失败证据，再按统一质量规则及拒绝清单从新数据和旧FIT回放中排除；如涉及旧DEV，选模使用父/新模型相同的清洁分母，旧全量口径仅另作诊断。继承的父权重/标准化器保留历史身份，不据此追认原历史文章全部无噪。原5632源与新源可做完整SimHash排除；更早历史清单只有SHA/URL而缺全文/SimHash的条目，只声明实际可完成的匹配。

## 训练、选择和资源

每轮50万次抽样：新增包装60%、旧 FIT 回放40%；新增内部 paired/context=60/40。旧 FIT 缓存固定25万条分层回放索引，保留原 cache SHA 和输入身份，不将旧缓存伪装成新提取。层内平衡存在角色并按家族归一，不叠加类别损失权重。

三候选均为 MLP128、seed17，使用相同旧 mean/scale：

| 候选 | 初始化/更新 | learning rate |
|---|---|---:|
| warm-all | 父最佳权重、更新全部 MLP | 1e-4 |
| warm-output | 父最佳权重、只更新最终六类输出层 | 3e-4 |
| scratch | 随机初始化、更新全部 MLP | 1e-3 |

统一 AdamW wd=1e-3、batch4096、dropout0.1、clip5、最多20轮/至少10轮/patience4。旧模型原样保留为基线。新候选仅按两组文章 DEV 选择：两组六类总体P/R均>=90%，旧DEV macro-F1相对父模型下降<=0.5个百分点，U/T→S/D误报<=1%的候选优先；再按新增DEV足量分组的S/D最弱召回、结构等权macro-F1、NLL、固定候选ID排序。弱组至少16源且128个正例。若无候选达标，仍导出最佳实验候选并明示未通过，不覆盖原默认模型。

GPU0承载 embedding+0–11层，GPU1承载12–23层，GPU2承载24–35层+norm/lm_head。大模型B1、无梯度、提取不使用KV cache，同步CPU跨卡中转。预检最长4096 token，固定输入/形状重复三次特征及hidden逐位一致，hook无扰动，设备全局采样峰值<=40GiB。提取结束释放120B，再每卡一个候选并行训练；冻结后重载本体提取新TEST。

| 相对时间 | 阶段 |
|---|---|
| 0–0.5h | 三卡预检、固定64源小试计时 |
| 0.5–3h | 新 FIT/DEV 原16头提取 |
| 3–3.5h | 三候选训练、仅DEV冻结 |
| 3.5–4.75h | 全新文章TEST提取/评分、本地57任务缓存复评 |
| 4.75–6h | 独立复算、图表/报告、本地备份和校验 |

按长度桶小试估计剩余耗时并增加25%余量，计时不含分类成绩。GPU调度/恢复不重设六小时起点，独立监督器只匹配本轮精确脚本与运行根，到截止终止本轮GPU进程。
