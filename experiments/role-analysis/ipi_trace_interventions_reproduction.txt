WorldSim policy
---------------
WorldSim is openai/gpt-4.1, temperature 0, max_tokens8192. Its system
instruction bounds the response to 12000 characters and asks for an explicitly
marked bounded prefix or task-relevant excerpt for long listings/DOM/code/logs.
Established facts and task-critical identifiers/content must be retained; if that
is impossible within the budget, return an explicit simulated output-limit error.
The client accepts only nonempty normally stopped content within the character
budget. Over-budget or length responses remain raw error evidence and are never
locally clipped or converted into success. The collector tries at most four
WorldSim requests per call. Only tool schemas, complete visible clean history,
and the current call are supplied. Private generated analysis and fixture attack
description/objective/judge/criteria are excluded. Provider responses/usage/errors
are recorded. Remote temperature-zero responses can still vary across reruns.

Resume semantics
----------------
Do not rerun a stage's prepare command after inputs/protocol are frozen; it
intentionally refuses to refreeze. Resume with the same collect or run command.
Collection signatures bind the prepared case, protocol and collection code.
Completed matching cases are reused, including the actual pilot during all-stage
collection. An unsuccessful case is preserved as an attempt record before retry.
New remote simulator calls on a failed-case retry may differ; both attempts stay
auditable. Never copy a partial generated response into a success tool return.

Replay signatures bind exact input/target/original coordinates, source trace,
wrapper catalog, runtime code and checkpoint. Completed matching per-input NPZ,
hiddenstate and record caches can be reused. Resume cache presence alone is not
full integrity verification: rerun the independent cap0 validator after the stage
is complete to stream all BF16 payloads, check all36 residual layers plus embedding
and final norm, and independently recompute every probe row. The separate Parquet
auditor compares every saved float32 logit/probability bit pattern and coordinate
against NPZ without rereading full residual payloads. Do not patch signatures,
use positive probe-row-cap for a final audit, or claim success for incomplete data.

Hiddenstate scope is selected first-role body tokens only. Baseline stores the
union of present first-role bodies; each variant stores its manipulated body.
The index gives exact paths/bytes/SHA and layer coverage. These are not hidden
states for every token of the full conversation. Keep the original immutable
source traces, collection records and stopping metadata alongside all readouts.
