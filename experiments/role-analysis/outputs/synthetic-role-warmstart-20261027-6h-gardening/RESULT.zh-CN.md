新候选将 57 个 system token 中的 **40 个误判为 developer**，14 个判为思考段，1 个判为 user。总体约94%的成绩主要来自其余859个正文位置全部正确，不能掩盖 system 退化。本例没有 developer 或 tool 正文，其召回无定义；developer 误报由19个增加至40个。

三种原文格式均已补测：原生角色准确率95.41%→94.00%；全部放入user后的**原语义对齐率**92.36%→92.25%；去标签后的原语义对齐率97.05%→96.40%。后两项不能当作原生角色准确率，all-user的实际user角色准确率另列完整指标。

本次只对作者固定原文做三次冻结120B前向，共约17.87秒GPU时间；没有重新生成回答、训练或重选候选。使用此前六小时预算的同一绝对截止时间，没有延长或重新计时。GPU进程已结束，新特征和概率已完整保存本地。

独立Torch CPU重算覆盖三格式×916位置×两模型共5,496行：argmax差异0，最大概率差3.815×10⁻⁶，306个指标标量完全一致。新模型仍是未通过DEV门槛的研究候选，不替换旧默认模型；这一个历史例子也不代表真实提示总体表现。
